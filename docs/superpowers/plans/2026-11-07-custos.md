# Custos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Custos, an AI accounts-payable agent on QoreChain testnet whose classical keys can only move money into a vault, and whose payouts need an ML-DSA-87 signature verified on-chain with `pqcVerify`.

**Architecture:** A Solidity vault (`CustosVault`) holds the operating float and verifies every payout and owner operation with the PQC precompiles. Three TypeScript processes share one core library: the Brain (Claude, no keys) turns invoices into proposals, the Keeper (deterministic policy + the agent's ML-DSA-87 key) signs intents and sends them through just-in-time scoped EVM windows, and the Sentinel watches the window and nonce. A CLI covers setup, owner operations and the Attack Lab; a Vite console shows the four locks.

**Tech Stack:** Solidity 0.8.28 + Foundry 1.9; Node 22, TypeScript, npm workspaces, tsx, vitest; `@qorechain/sdk` 0.12.0, `@qorechain/qoresign` 0.1.1, `@qorechain/evm` 0.12.0, viem; `@anthropic-ai/sdk` (Claude Opus 5.5, `claude-opus-5-5`); `@modelcontextprotocol/sdk` + `@qorechain/mcp`; Vite + React.

**Spec:** Claude Doc "Post-Quantum AI Agents — QoreChain Hackathon Plan" (https://claude.ai/artifact/9MuGsFSSMQougYGnYimzca), approved 7 Nov 2026. Builder: solo.

## Global Constraints

- Network: testnet `qorechain-diana`, EVM chain ID 9800, REST `https://api-testnet.qore.host`, RPC `https://rpc-testnet.qore.host`, EVM RPC `https://evm-testnet.qore.host`, explorer `https://explore.qore.network`.
- Precompiles (lowercase in code): `pqcVerify(bytes pubkey, bytes signature, bytes message) returns (bool)` at `0x0000000000000000000000000000000000000a01`; `pqcKeyStatus(address) returns (bool registered, uint8 algorithmId, bytes pubkey, bool possessionProven)` at `0x0000000000000000000000000000000000000a02`. ML-DSA-87 = algorithm id 1, pubkey 2592 bytes, signature 4627 bytes.
- Every ML-DSA-87 signature Custos makes uses the QoreSign message domain: signed bytes = `"qorechain-msg-v1|" + "qorechain-diana" + "|"` followed by the ABI-encoded payload. Verified against the live precompile on 7 Nov 2026 (spike: valid → true, tampered → false).
- Payload domain tags: `CUSTOS_PAY_V1`, `CUSTOS_APPROVED_PAY_V1`, `CUSTOS_POLICY_V1`, `CUSTOS_PAYEE_V1`, `CUSTOS_PAUSE_V1`, `CUSTOS_UNPAUSE_V1`, `CUSTOS_WITHDRAW_V1`. Every payload binds `block.chainid` and the vault address.
- fUSD ERC-20 `0x97143B771D34ddb9130b807b135Ae675A5a963CA` (6 decimals); token `address(0)` means native QOR (fallback if `MsgConvertCoin` fails).
- Windows: 50 blocks, 1 transaction, fee-only value, `allowedTargets = [vault]` (deploy uses an unscoped window, because a scoped window refuses contract creation).
- Treasury rules: `allowedEvmCalls = ["<vault>/<topUp selector>"]`, linked key permission `["evm"]`, expiry 7 days. `MsgExecuteEVM.nonce` is the per-authenticator counter from `fetchAuthNonce`.
- The linked (authenticator) key is a separate secp256k1 key, never the drill account's key.
- No git commits (user instruction). Nothing may be written to drive C: (it is full); npm cache and temp go to D:.
- Licence Apache-2.0; every kit and library credited in the README.

## Review Focus

- An invoice amount with decimals or thousands separators ("1,250.50 fUSD") must convert to exact base units or be rejected, never rounded. Test: `core/test/amounts.test.ts`.
- A second payment for the same invoice (same invoice hash) must be refused even with a fresh nonce. Test: vault `test_RevertWhen_InvoicePaidTwice` and Keeper `rejects duplicate invoice`.
- A daily cap must reset at the UTC day boundary and not before. Test: vault `test_DailyCapResetsNextUtcDay`.
- Keeper restart in the middle of a payment (window open, tx not sent) must not double-pay or leave a window open. Test: keeper `recovers open window on start`.
- A precompile that returns empty data (inactive network) must make the vault revert, not pass. Test: vault `test_RevertWhen_PrecompileReturnsEmpty`.
